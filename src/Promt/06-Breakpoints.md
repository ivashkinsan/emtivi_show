# Назначение

Данный документ определяет адаптивную архитектуру приложения EMTIVI.

Проект проектируется исключительно по принципу Mobile First.

Каждый новый компонент сначала разрабатывается для смартфона.

Только после завершения мобильной версии допускается адаптация под планшет, ноутбук и десктоп.

Запрещается проектировать интерфейс "от десктопа".

---

# Философия

EMTIVI — это мобильное приложение, которое масштабируется до планшета, ноутбука, телевизора и широкоформатных экранов.

Desktop не является основной платформой.

Desktop — это расширение Mobile.

---

# Breakpoints

Используются только следующие точки перехода.

```css
--bp-xs: 320px;
--bp-sm: 375px;
--bp-md: 480px;
--bp-lg: 768px;
--bp-xl: 1024px;
--bp-2xl: 1280px;
--bp-3xl: 1440px;
--bp-4xl: 1920px;
```

Запрещено создавать собственные breakpoints.

# Responsive Strategy

Не существует отдельных версий сайта.

Существует один интерфейс, который постепенно расширяется.

Каждый новый breakpoint только добавляет пространство.

Он не меняет архитектуру.

• декоративные элементы.

---

# Performance

Каждый breakpoint обязан сохранять 60 FPS.

Не допускается:

• тяжелых blur;

• больших box-shadow;

• постоянных repaint;

• сложных фильтров на мобильных устройствах.

---

# Accessibility

Все breakpoints обязаны соблюдать:

• минимальный размер зоны нажатия 44×44 px;

• читаемость текста;

• поддержку масштабирования браузера;

• клавиатурную навигацию на Desktop;

• корректную работу Screen Reader.

---

# Запрещено

❌ Отдельная мобильная версия.

❌ Отдельный desktop-проект.

❌ Скрытие контента без причины.

❌ Фиксированные ширины компонентов.

❌ Использование px там, где возможно применить относительные единицы.

❌ Произвольные media queries.

❌ Дублирование компонентов для разных устройств.

---

# Правила разработки

Каждый компонент обязан:

• корректно отображаться на всех breakpoints;

• использовать только утвержденные точки перехода;

• не иметь собственной логики адаптации, если она может быть вынесена в Layout;

• использовать CSS Grid и Flexbox вместо абсолютного позиционирования.

---

# Definition of Done

Адаптивная система считается завершенной, если:
• приложение корректно работает от 320px до 4K;
• отсутствуют горизонтальные скроллы;
• все компоненты масштабируются без изменения структуры;
• интерфейс остается узнаваемым на любом устройстве;
• Mobile является первичной платформой, а Desktop — её логичным расширением.
