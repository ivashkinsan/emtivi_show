# Назначение

Данный документ определяет правила построения всей типографики проекта EMTIVI.

Все текстовые элементы приложения обязаны использовать только заранее определенные типографические токены.

Запрещается использовать произвольные размеры шрифта, высоту строки, насыщенность или межбуквенное расстояние.

Типографика должна создавать ощущение современного музыкального приложения премиум-класса, вдохновленного Apple Music, VisionOS и интерфейсами OLED-телевизоров.

---

# Принципы

Типографика должна быть:

• лаконичной;

• контрастной;

• хорошо читаемой на OLED-дисплеях;

• визуально "воздушной";

• не перегруженной;

• ориентированной на мобильные устройства.

# Переносы

Запрещены "висячие" предлоги.

Минимизировать одиночные слова на новой строке.

Использовать text-wrap: balance там, где поддерживается.

---

# Адаптивность

Типографика проектируется Mobile First.

Размеры увеличиваются только через breakpoints.

Никогда не использовать отдельные размеры для каждого устройства.

Использовать fluid typography через clamp().

Например:

Display XL

clamp(min, preferred, max)

Body

clamp(min, preferred, max)

Это обеспечивает плавное масштабирование.

# Definition of Done

Типографическая система считается завершенной, если:

• любой текстовый элемент приложения собирается только из заранее определенных токенов;

• все размеры масштабируются через clamp();

• отсутствуют жестко заданные значения font-size, line-height и letter-spacing в компонентах;

• каждый тип текста имеет четкое назначение и не дублирует другие стили.
