# Назначение

Этот документ является единственным источником истины для всех UI-компонентов приложения EMTIVI.

Если `07-COMPONENTS.md` определяет список компонентов, то данный документ определяет их внешний вид, размеры, состояния, поведение, анимации и правила использования.

Любой компонент приложения должен соответствовать данной спецификации.

Компоненты не должны придумывать собственный внешний вид.

---

# Общие правила

Каждый компонент обязан:

• использовать CSS Modules

• использовать Design Tokens

• использовать только CSS Variables

• поддерживать Mobile First

• быть полностью типизированным

• использовать React.memo где это оправдано

• не содержать inline styles

• не содержать magic numbers

• использовать prefers-reduced-motion

• иметь Accessibility

# Definition of Done

Компонент считается завершенным только если:

• соответствует данной спецификации;

• использует исключительно токены дизайн-системы;

• полностью адаптивен;

• протестирован на мобильных устройствах;

• поддерживает Accessibility;

• не зависит от конкретного экрана;

• может быть переиспользован без изменений в любом разделе приложения.
