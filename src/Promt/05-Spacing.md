# Назначение

Данный документ определяет пространственную систему интерфейса EMTIVI.

Все расстояния, размеры, контейнеры, сетки и внутренние отступы строятся исключительно на основе данной системы.

Запрещается использовать произвольные значения margin, padding, gap, width и height.

Любое расстояние должно быть выражено через дизайн-токены.

Главная цель — создать визуальный ритм и ощущение "дорогого" интерфейса.

---

# Пространственная философия

Интерфейс EMTIVI должен "дышать".

Контент никогда не должен быть прижат к краям экрана.

Между элементами всегда остается достаточно воздуха.

Свободное пространство является таким же элементом дизайна, как цвет или типографика.

Каждый экран должен ощущаться спокойным и премиальным.

---

# Базовая единица

Все размеры строятся от одной базовой единицы.

```text
Base Unit = 4px
```

Любой размер кратен 4.

Допускаются только значения из токенов.

# Правила разработки

Каждый новый компонент обязан использовать spacing tokens.

Если необходим новый размер —

сначала обновляется данный документ.

После этого обновляется Design System.

Только затем изменяется компонент.

---

# Definition of Done

Пространственная система считается завершенной, если:

• любой компонент использует только spacing tokens;

• отсутствуют произвольные значения margin, padding и gap;

• весь интерфейс построен на едином вертикальном и горизонтальном ритме;

• мобильная версия остается основной точкой проектирования;

• интерфейс сохраняет одинаковые пропорции на всех устройствах.
