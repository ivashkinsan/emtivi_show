# Документация по структуре проекта

Этот документ описывает основную структуру папок в директории `src`.

## Корневая директория `src`

-   `App.tsx`: Главный компонент-контейнер приложения.
-   `index.jsx`: Точка входа, рендерящая `App` в DOM.
-   `vite-env.d.ts`: Определения типов для Vite.

## Основные директории

-   `app/`: Содержит основную логику приложения, включая корневой компонент `AppContent` и провайдеры.
-   `channels/`: Содержит компоненты для каждого отдельного "канала" или страницы (`CH01-Home`, `CH02-About`, и т.д.).
-   `components/`: Содержит переиспользуемые UI-компоненты, разделенные на `atoms`, `molecules`, `organisms`.
-   `docs/`: Документация проекта (вы находитесь здесь).
-   `hooks/`: Кастомные React-хуки (например, `useChannelTransition`).
-   `img/`: Статичные изображения.
-   `lib/`: Библиотеки и константы (например, данные о музыкантах).
-   `pages/`: *Устаревшая папка*, контент был перенесен в `channels`.
-   `Promt/`: Исходные тексты и брифы для разработки.
-   `store/`: Глобальное управление состоянием с использованием Zustand (`channelStore`, `uiStore`).
-   `styles/`: Глобальные стили, CSS-переменные (токены) и сбросы.
