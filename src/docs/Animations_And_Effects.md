# Документация анимаций и эффектов

Этот документ описывает реализацию визуальных эффектов: начальной анимации загрузки и параллакса фона.

## 1. Начальная анимация загрузки (App Startup)

Реализована в `src/app/App.tsx`.

### Логика работы:
1.  **Начало:** Приложение рендерится с `isLoaded = false`. Отрисовывается только `ExperimentalLogoLoader`.
2.  **Задержка:** `useEffect` с `setTimeout` (3500мс) удерживает лоадер.
3.  **Схлопывание:** Через 3 секунды `ExperimentalLogoLoader` активирует внутреннюю анимацию схлопывания (`shrinking`).
4.  **Разворачивание:** Через 3.5 секунды `isLoaded` становится `true`.
5.  **Переход:** `contentWrapper` переключается на класс `.isLoaded` (CSS), который анимирует `scale` и `opacity` (2с), плавно разворачивая контент приложения.

### Ключевые компоненты:
*   `src/app/App.tsx`: Управление состоянием и переключение между `ExperimentalLogoLoader` и контентом.
*   `src/components/atoms/Loader/ExperimentalLogoLoader.tsx`: SVG-логотип с анимацией заполнения (использует `animate` внутри `clipPath`) и схлопывания.
*   `src/app/App.module.css`: CSS-анимации разворачивания (`contentWrapper`).

## 2. Параллакс фона

Реализован для создания эффекта глубины на стартовом канале (`CH01-Home`).

### Логика работы:
1.  **Хук `useParallax` (`src/hooks/useParallax.ts`):** Слушает события `mousemove` и `deviceorientation`. Возвращает текущее смещение `x` и `y` на основе интенсивности движения.
2.  **Интеграция:** 
    *   Применяется в `TVShell` (`src/components/TV/TVShell/TVShell.tsx`).
    *   Параллаксный фон `.parallaxBackground` размещен внутри контейнера `.screen`.
3.  **Стилизация:**
    *   `.parallaxBackground` в `TVShell.module.css` имеет размер `110%` (чтобы избежать пустых краев при параллаксе) и зафиксирован с `z-index: 0`.
    *   Контейнер `.screen` имеет `overflow: hidden`, ограничивая видимость фона границами телевизора.

### Управление:
*   Интенсивность задается при вызове `useParallax(intensity)`.
*   Эффект активен только для канала `CH01`.
