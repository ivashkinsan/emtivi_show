# Подробное описание проекта "emtivi_show"

Этот документ предоставляет детальный обзор архитектуры, компонентов и зависимостей проекта.

## 1. Обзор проекта

**emtivi_show** — это веб-приложение, созданное с использованием React и Vite. Судя по структуре и названиям компонентов (`TV`, `SoundAnimation`), проект представляет собой интерактивный пользовательский интерфейс с визуальными и, возможно, звуковыми элементами, стилизованный под "телевизионную" тематику.

Навигация по приложению осуществляется через центральный компонент `Menu`, который позволяет переключать "страницы" или состояния.

## 2. Движок и основная логика

"Движком" приложения можно считать связку компонентов `TV` и `Menu`.

*   **`TV.tsx`**: Это главный контейнер и управляющий компонент.
    *   Он хранит состояние текущей активной "страницы" в `React.useState("HOME")`.
    *   Он передает функцию `handlerPage` в дочерний компонент `Menu`, позволяя ему изменять это состояние.
    *   В текущей реализации он рендерит только компонент `Menu`. Остальные визуальные части (`Logo`, `Background`, `SoundAnimation`) присутствуют в виде импортов, но их рендеринг закомментирован.

*   **`Menu.tsx`**: Это основной навигационный элемент.
    *   Он динамически генерирует набор кнопок (`MenuButton`) на основе объекта `svgIcons`, импортированного из `menu/svg/IconsAll.tsx`.
    *   Каждая кнопка представляет собой иконку. При наведении или при совпадении ее имени с текущей `page` иконка подсвечивается.
    *   По клику на кнопку вызывается `handlerPage(name)`, что изменяет состояние в родительском компоненте `TV`.

## 3. Компоненты

### 3.1. Ключевые компоненты

*   **`App.tsx`**: Корневой компонент, который рендерит `Home`.
*   **`Home.tsx`**: Промежуточный компонент, который рендерит `TV`.
*   **`TV.tsx`**: Основной контейнер, управляющий состоянием и рендерящий `Menu`.
*   **`Menu.tsx`**: Компонент навигации, управляющий выбором "страницы".
*   **`IconsAll.tsx`**: Файл, экспортирующий объект `svgIcons`, который содержит все SVG-иконки, используемые в меню.

### 3.2. Визуальные и прочие компоненты

*   **`SoundAnimation.tsx`**: Интересный самодостаточный компонент, который использует HTML5 Canvas (`<canvas>`) для рисования анимированной звуковой волны.
    *   Анимация создается в цикле с помощью `requestAnimationFrame`.
    *   Волны генерируются математически с использованием `Math.sin()`, а их цвет меняется в зависимости от положения, создавая радужный эффект (`hsl`).
    *   На данный момент этот компонент не используется (закомментирован).

*   **`logo/logo.tsx`**, **`logo/LogoLabel.tsx`**, **`main_content/background.tsx`**: Другие визуальные компоненты, которые существуют в проекте, но их рендеринг в настоящее время отключен.

## 4. Зависимости

Список зависимостей взят из файла `package.json`.

### 4.1. Основные зависимости (Dependencies)

*   `react`: Библиотека для создания пользовательских интерфейсов.
*   `react-dom`: Пакет для работы React с DOM.

### 4.2. Зависимости для разработки (Dev Dependencies)

*   `@vitejs/plugin-react`: Плагин для интеграции React с Vite.
*   `vite`: Современный и быстрый сборщик проектов.
*   `typescript`: Язык программирования, добавляющий статическую типизацию в JavaScript.
*   `eslint` и связанные плагины (`@eslint/js`, `typescript-eslint`, etc.): Инструменты для статического анализа кода, поиска ошибок и поддержания единого стиля.
*   `@types/react`, `@types/react-dom`: Пакеты, содержащие определения типов для React.
