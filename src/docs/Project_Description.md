# Подробное описание проекта "emtivi_show"

Этот документ предоставляет детальный обзор архитектуры, компонентов и зависимостей проекта в его текущем состоянии.

## 1. Обзор проекта

**emtivi_show** — это интерактивное веб-приложение, созданное с использованием React, Vite и TypeScript. Проект имитирует интерфейс "телевизора", где пользователь может переключаться между различными "каналами" (страницами), каждая из которых представляет раздел сайта музыкальной группы (О нас, Медиа, Контакты и т.д.).

Ключевой особенностью является сложный макет "TV-экрана", который включает в себя фиксированный хедер и футер внутри экрана, в то время как контент между ними прокручивается.

## 2. Архитектура и основная логика

"Движком" приложения является связка компонентов `App.tsx`, `TVShell.tsx` и хранилища состояния `channelStore`.

*   **`App.tsx`**: Является точкой входа в логику приложения. Он рендерит `TVShell` и управляет тем, какой контент должен отображаться на "экране". Он содержит основную логику макета, располагая `ChannelHeader`, `BottomNavigation` и прокручиваемый контейнер `channelContainer` в правильном порядке.

*   **`TVShell.tsx`**: Компонент, отвечающий за визуальное обрамление "телевизора" (рамки, фон, тени, свечение). Он не управляет логикой, а лишь предоставляет "экран" (`.screen`), в который `App.tsx` вставляет дочерние элементы.

*   **`channelStore.ts`**: Хранилище на базе **Zustand**, которое управляет глобальным состоянием: текущий выбранный канал (`currentChannel`) и флаг переключения (`isSwitching`).

*   **`useChannelTransition.ts`**: Кастомный хук, который подписывается на `channelStore` и управляет анимациями перехода между каналами, используя флаг `isSwitching`.

## 3. Компоненты

### 3.1. Ключевые компоненты макета

*   `App.tsx`: Корневой компонент, собирающий весь макет.
*   `TVShell.tsx`: Визуальная оболочка "телевизора".
*   `ChannelHeader.tsx`: Фиксированный хедер "экрана".
*   `BottomNavigation.tsx`: Фиксированный футер "экрана" с кнопками каналов.
*   `channelContainer` (CSS-модуль в `App.module.css`): Центральная область экрана, которая обеспечивает прокрутку контента.

### 3.2. "Каналы" (Страницы)

Компоненты каналов находятся в `src/channels/`. Каждый из них представляет собой страницу с уникальным контентом (`Home`, `About`, `Band` и т.д.). Они больше не содержат в себе хедер, так как он был вынесен на общий уровень в `App.tsx`.

## 4. Зависимости

Список зависимостей актуален на момент написания документа.

### 4.1. Основные зависимости (Dependencies)

*   `react`: Библиотека для создания пользовательских интерфейсов.
*   `react-dom`: Пакет для работы React с DOM.
*   `zustand`: Легковесная библиотека для управления состоянием.

### 4.2. Зависимости для разработки (Dev Dependencies)

*   `@vitejs/plugin-react`: Плагин для интеграции React с Vite.
*   `vite`: Современный и быстрый сборщик проектов.
*   `typescript`: Язык программирования, добавляющий статическую типизацию в JavaScript.
*   `eslint` и связанные плагины: Инструменты для статического анализа кода.
*   `@types/react`, `@types/react-dom`: Пакеты, содержащие определения типов для React.
